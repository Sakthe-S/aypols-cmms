🎨 Frontend Framework
Next.js 14.2 (App Router)
  • React Server Components for fast, SEO-friendly pages
  • Client components only where interactivity needed (Sidebar, Login)
  • Route groups (dashboard) for shared auth layout
  • TypeScript for type safety end-to-end

Key files

src/app/(dashboard)/layout.tsx → auth guard + sidebar src/components/Sidebar.tsx → navigation (client)
🔐 Authentication
NextAuth.js v4 + JWT sessions
  • Credentials provider (email + password)
  • Passwords hashed with bcryptjs
  • Role-based access: EMPLOYEE / TECHNICIAN / SUPERVISOR / STORE_ADMIN / EHS_OFFICER / ADMIN
  • Middleware protects all dashboard pages
src/lib/auth.ts → NextAuth config src/middleware.ts → route protection src/app/login/ → sign-in page
🗄️ Database & ORM
Prisma ORM 5 → SQLite
  • Single client singleton (prevents connection leaks in dev)
  • Raw SQL for column-vs-column comparisons (low-stock logic)
  • Transactions for atomic operations (deduct stock + log + link part)
prisma/schema.prisma → 16 models src/lib/prisma.ts → singleton client prisma/seed.ts → demo data
🔄 Data Flow (Server Actions)
Mutation pattern — forms submit direct to server actions:
  • No separate REST endpoints needed for CRUD
  • revalidatePath() refreshes UI after mutations
  • redirect() after successful operations
async function completeWork(formData) { 'use server' // 1. read formData // 2. calculate costs // 3. prisma.maintenanceTicket.update(...) // 4. revalidatePath + redirect }
⚡ Cross-cutting Logic

Cost Engine (REQ-6.8)

  • Parts Cost = Σ(qty × unit price)
  • Labor Cost = hours × rate
  • Total = Parts + Labor + Contractor + Other
  • Rolls up to machine lifetime cost at closure

Inventory Engine

  • Auto-deduct stock when parts logged on a ticket
  • Immutable stock_transactions ledger
  • Low-stock detection using raw SQL

Reminder Engine

  • Triggers on dashboard load
  • Checks PM / AMC / calibration / training due dates
  • Dedup via 24h window; generates in-app notifications
